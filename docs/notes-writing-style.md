# 笔记写作风格（notes/）

> 定稿 2026-08-22。CLAUDE.md 引用本文件；写 `notes/<日期>-<项目>.md` 前先读这里。

## 定位

`notes/` 笔记 = **系列结构 + 卡兹克文风**（文风来自 khazix-writer skill，规则已内联在此，不依赖该 skill 是否可用）。

## 结构（系列惯例）

- 标题：`# <日期> — <项目>，一句话主题`
- 开篇：`## 事情是这样的`
- 主体：`##` 小标题分段（**不加目录**，不加公众号固定尾部）
- 跨篇引用前几篇（「上篇写了…」「sql_check 那篇讲过」）
- 源码引用（deepseek-harness 源码路径 + 本仓库 `examples/` 路径）并带代码块节选
- 坑 / 测试 / 验证逐段展开
- 收尾：`## 接下来该干嘛`

## 文风（卡兹克味）

- 第一人称口语化、自嘲与承认不足、私人视角连接
- 契诃夫之枪回环收尾（开头埋钩子结尾响）
- 文化升维、具体工具名不空泛

## 硬性规则（正文保留，代码块除外）

- 不用冒号「：」、破折号「——」、双引号（强调用「」）
- 禁用词：说白了 / 意味着 / 本质上 / 换句话说 / 不可否认 / 综上所述 / 总的来说 / 值得注意的是 / 不难发现 / 让我们 / 在当今 / 随着
- 不罗列 bullet 观点
- 情绪标点（？？？/。。。）可用
- 可适量加粗术语（**小标题和加粗是用户明确覆盖的卡兹克禁区**，按系列惯例保留）

## 自检

写完跑卡兹克四层自检的 L1 扫描（禁用词 / 禁用标点 / 空泛工具名）必须零命中，结构项按上述系列惯例。
